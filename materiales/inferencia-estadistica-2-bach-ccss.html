Inferencia Estadística e Intervalos de Confianza

Muestreo, Distribuciones Muestrales, Intervalos para Media y Proporción, Error Máximo y Tamaño Muestral

Formulario Esencial EBAU (Chuleta Rápida)

1. Para la Media Poblacional $\mu$

Distribución muestral: $\bar{X} \sim N\left(\mu, \, \frac{\sigma}{\sqrt{n}}\right)$

$$IC = \left(\bar{x} - z_{\alpha/2} \frac{\sigma}{\sqrt{n}}, \; \bar{x} + z_{\alpha/2} \frac{\sigma}{\sqrt{n}}\right)$$

Error: $E = z_{\alpha/2} \frac{\sigma}{\sqrt{n}}$ • Tamaño: $n = \left(\frac{z_{\alpha/2} \cdot \sigma}{E}\right)^2$

2. Para la Proporción Poblacional $p$

Distribución: $\hat{P} \sim N\left(p, \, \sqrt{\frac{p(1-p)}{n}}\right)$

$$IC = \left(\hat{p} - z_{\alpha/2} \sqrt{\frac{\hat{p}(1-\hat{p})}{n}}, \; \hat{p} + z_{\alpha/2} \sqrt{\frac{\hat{p}(1-\hat{p})}{n}}\right)$$

Error: $E = z_{\alpha/2} \sqrt{\frac{\hat{p}(1-\hat{p})}{n}}$ • Tamaño: $n = \frac{z_{\alpha/2}^2 \cdot \hat{p}(1-\hat{p})}{E^2}$

Valores críticos frecuentes $z_{\alpha/2}$:
90% $\implies z_{\alpha/2} = 1.645$ 95% $\implies z_{\alpha/2} = 1.96$ 99% $\implies z_{\alpha/2} = 2.575$
1

Población, Muestra y Métodos de Muestreo

La inferencia estadística es la rama de las matemáticas que permite extraer conclusiones sobre una población completa a partir del análisis de una parte representativa de ella, denominada muestra.

Muestreo Aleatorio Simple

Cada individuo de la población tiene exactamente la misma probabilidad de ser elegido. Se realiza mediante sorteo, tablas o números aleatorios.

Muestreo Sistemático

Se ordenan los elementos y se toma 1 cada $k = N/n$ elementos (coeficiente de elevación), tras elegir el primero al azar entre $1$ y $k$.

Muestreo Estratificado

La población se divide en estratos homogéneos (edades, sexos, cursos). Con afijación proporcional, el número de elementos en el estrato $i$ es:

$$\frac{n_i}{N_i} = \frac{n}{N} \implies n_i = n \cdot \frac{N_i}{N}$$

2

Distribución Muestral de Medias y Teorema Central del Límite

Consideremos una variable $X$ con media poblacional $\mu$ y desviación típica $\sigma$. Si extraemos muestras aleatorias de tamaño $n$:

Teorema Central del Límite (TCL):

Si la población original es normal $N(\mu, \sigma)$, o si el tamaño muestral es suficientemente grande ($n \ge 30$), la media de las muestras $\bar{X}$ sigue una distribución aproximadamente normal:

$$\bar{X} \sim N\left(\mu, \; \frac{\sigma}{\sqrt{n}}\right)$$
  • Media de las medias muestrales: $\mu_{\bar{x}} = \mu$ (estimador insesgado).
  • Desviación típica de la media (error típico): $\sigma_{\bar{x}} = \frac{\sigma}{\sqrt{n}}$. A mayor tamaño de muestra, menor es la dispersión de las medias.
  • Para tipificar: $Z = \frac{\bar{X} - \mu}{\sigma / \sqrt{n}} \sim N(0, 1)$.
3

Distribución Muestral de Proporciones

Cuando la variable estudiada es dicotómica (éxito/fracaso) con proporción poblacional de éxito $p$ ($q = 1 - p$), la proporción muestral $\hat{P} = \frac{X}{n}$ (donde $X \sim B(n, p)$) puede aproximarse mediante una normal si $n \cdot p \ge 5$ y $n \cdot (1-p) \ge 5$:

$$\hat{P} \sim N\left(p, \; \sqrt{\frac{p(1-p)}{n}}\right)$$

Para tipificar: $Z = \frac{\hat{P} - p}{\sqrt{\frac{p(1-p)}{n}}} \sim N(0, 1)$.

4

Nivel de Confianza ($1 - \alpha$) y Valor Crítico $z_{\alpha/2}$

El nivel de confianza es la probabilidad $1 - \alpha$ de que el parámetro desconocido ($\mu$ o $p$) quede dentro del intervalo calculado. El valor crítico $z_{\alpha/2}$ es el valor de la normal estándar $N(0, 1)$ que deja un área central igual a $1 - \alpha$, dejando un área de $\alpha/2$ en cada una de las dos colas.

Pasos para calcular $z_{\alpha/2}$ con la tabla de la $N(0, 1)$:
  1. Identificar el nivel de confianza: $1 - \alpha$ (por ejemplo, al $95\% \implies 1 - \alpha = 0.95$).
  2. Hallar el nivel de significación: $\alpha = 1 - 0.95 = 0.05 \implies \frac{\alpha}{2} = 0.025$.
  3. Calcular la probabilidad acumulada hasta $z_{\alpha/2}$: $$P(Z \le z_{\alpha/2}) = 1 - \frac{\alpha}{2} = 1 - 0.025 = 0.975$$
  4. Buscar en el interior de la tabla normal el valor $0.9750 \implies \mathbf{z_{\alpha/2} = 1.96}$.
Nivel de Confianza ($1 - \alpha$) Significación ($\alpha$) Cola ($\alpha/2$) Probabilidad $1 - \alpha/2$ Valor Crítico ($z_{\alpha/2}$)
90% (0.90) 0.10 0.05 0.9500 1.645
95% (0.95) 0.05 0.025 0.9750 1.96
99% (0.99) 0.01 0.005 0.9950 2.575

Intervalos de Confianza y Error Máximo Admisible ($E$)

Para la Media Poblacional ($\mu$)

Se conoce o estima la desviación típica $\sigma$ y la media muestral $\bar{x}$ con una muestra de tamaño $n$:

$$IC = \left(\bar{x} - E, \; \bar{x} + E\right)$$

Error Máximo Admisible ($E$):

$$E = z_{\alpha/2} \frac{\sigma}{\sqrt{n}}$$

Para la Proporción Poblacional ($p$)

A partir de una muestra de tamaño $n$ con proporción observada $\hat{p} = \frac{x}{n}$:

$$IC = \left(\hat{p} - E, \; \hat{p} + E\right)$$

Error Máximo Admisible ($E$):

$$E = z_{\alpha/2} \sqrt{\frac{\hat{p}(1-\hat{p})}{n}}$$
6

Determinación del Tamaño Muestral Mínimo ($n$)

En los problemas de diseño experimental y exámenes EBAU, se pide habitualmente calcular cuántos individuos hay que examinar como mínimo para garantizar que el error cometido no supere una cota prefijada $E$:

Para la Media Poblacional:

Despejando $n$ de la fórmula del error $E = z_{\alpha/2} \frac{\sigma}{\sqrt{n}}$:

$$n = \left(\frac{z_{\alpha/2} \cdot \sigma}{E}\right)^2$$

Regla: Si el resultado contiene decimales, se redondea siempre al entero superior para asegurar que el error sea $\le E$.

Para la Proporción Poblacional:

Despejando $n$ de $E = z_{\alpha/2} \sqrt{\frac{\hat{p}(1-\hat{p})}{n}}$:

$$n = \frac{z_{\alpha/2}^2 \cdot \hat{p}(1-\hat{p})}{E^2}$$

Caso más desfavorable: Si no se dispone de ningún valor preliminar de $\hat{p}$, se toma $p = 0.5$, que maximiza el producto $p(1-p) = 0.25$.

Propiedades Clave para Preguntas Inversas y Teóricas de EBAU Cantabria

1. Centro y Radio del Intervalo:

Si nos dan directamente el intervalo $(a, b)$ sin especificar la media o el error:

  • El centro es la media muestral o proporción muestral: $\bar{x} = \frac{a + b}{2}$ (o $\hat{p} = \frac{a + b}{2}$).
  • El radio es el error máximo: $E = \frac{b - a}{2}$.
  • La amplitud o longitud del intervalo es $L = b - a = 2E$.
2. Relaciones Cualitativas y Variaciones:
  • Si aumentamos el nivel de confianza ($1-\alpha$): El valor crítico $z_{\alpha/2}$ aumenta $\implies$ el error $E$ aumenta $\implies$ el intervalo es más ancho (menos preciso pero más seguro).
  • Si aumentamos el tamaño de la muestra ($n$): $\sqrt{n}$ está en el denominador $\implies$ el error $E$ disminuye $\implies$ el intervalo es más estrecho (más preciso).
  • Para reducir el error a la mitad ($E' = E/2$): Es necesario cuadruplicar el tamaño muestral ($n' = 4n$).
