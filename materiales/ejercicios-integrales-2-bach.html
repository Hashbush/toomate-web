Nivel 1

Integrales Inmediatas, Sustitución y Barrow Elemental (1 a 8)

Ejercicio 1 Integral polinómica

Calcula la integral indefinida: $\int (3x^4 - 5x^2 + 2x - 7) \, dx$.

Ver Solución Paso a Paso

Aplicamos $\int x^n \, dx = \frac{x^{n+1}}{n+1} + C$ término a término:

$$= 3 \frac{x^5}{5} - 5 \frac{x^3}{3} + 2 \frac{x^2}{2} - 7x + C = \mathbf{\frac{3}{5}x^5 - \frac{5}{3}x^3 + x^2 - 7x + C}$$

Ejercicio 2 Tipo logarítmico

Calcula: $\int \frac{2x}{x^2 + 5} \, dx$.

Ver Solución Paso a Paso

El numerador es exactamente la derivada del denominador $(x^2 + 5)' = 2x$:

$$\int \frac{f'(x)}{f(x)} \, dx = \mathbf{\ln|x^2 + 5| + C}$$

Ejercicio 3 Ajuste de constante

Calcula: $\int \frac{x}{3x^2 + 1} \, dx$.

Ver Solución Paso a Paso

La derivada del denominador es $6x$. Multiplicamos y dividimos por 6:

$$= \frac{1}{6} \int \frac{6x}{3x^2 + 1} \, dx = \mathbf{\frac{1}{6} \ln(3x^2 + 1) + C}$$

Ejercicio 4 Función exponencial

Calcula: $\int x \cdot e^{x^2} \, dx$.

Ver Solución Paso a Paso

Forma $\int f'(x) e^{f(x)} \, dx$. Derivada del exponente: $(x^2)' = 2x$:

$$= \frac{1}{2} \int 2x \, e^{x^2} \, dx = \mathbf{\frac{1}{2} e^{x^2} + C}$$

Ejercicio 5 Tipo arcotangente

Calcula: $\int \frac{1}{1 + 4x^2} \, dx$.

Ver Solución Paso a Paso

Escribimos $4x^2 = (2x)^2$. La derivada de $2x$ es 2:

$$= \frac{1}{2} \int \frac{2}{1 + (2x)^2} \, dx = \mathbf{\frac{1}{2} \arctan(2x) + C}$$

Ejercicio 6 Regla de Barrow directa

Calcula la integral definida: $\int_1^3 (3x^2 - 2x + 1) \, dx$.

Ver Solución Paso a Paso

Primitiva: $F(x) = x^3 - x^2 + x$.

$$F(3) = 3^3 - 3^2 + 3 = 27 - 9 + 3 = 21$$

$$F(1) = 1^3 - 1^2 + 1 = 1$$

$$\int_1^3 f(x) \, dx = F(3) - F(1) = 21 - 1 = \mathbf{20}$$

Ejercicio 7 Barrow con trigonométricas

Evalúa: $\int_0^{\pi/2} \cos x \, dx$.

Ver Solución Paso a Paso

Primitiva: $F(x) = \sin x$.

$$[\sin x]_0^{\pi/2} = \sin(\pi/2) - \sin(0) = 1 - 0 = \mathbf{1}$$

Ejercicio 8 Cálculo de constante C

Determina la función $f(x)$ que cumple $f'(x) = 6x - 4$ y pasa por el punto $P(2, 5)$.

Ver Solución Paso a Paso

Integrando: $f(x) = \int (6x - 4) \, dx = 3x^2 - 4x + C$.

Imponemos $f(2) = 5$: $3(2)^2 - 4(2) + C = 5 \implies 12 - 8 + C = 5 \implies 4 + C = 5 \implies C = 1$.

$$\mathbf{f(x) = 3x^2 - 4x + 1}$$

Nivel 2

Integración por Partes, Racionales y Áreas Básicas (9 a 16)

Ejercicio 9 Partes: x·e^x

Calcula por partes: $\int x \cdot e^x \, dx$.

Ver Solución Paso a Paso

Elegimos: $u = x \implies du = dx$; $dv = e^x dx \implies v = e^x$.

$$\int x e^x dx = x e^x - \int e^x dx = x e^x - e^x + C = \mathbf{e^x(x - 1) + C}$$

Ejercicio 10 Partes: logaritmo

Calcula: $\int \ln x \, dx$.

Ver Solución Paso a Paso

$u = \ln x \implies du = \frac{1}{x}dx$; $dv = dx \implies v = x$.

$$\int \ln x dx = x \ln x - \int x \frac{1}{x} dx = x \ln x - \int 1 dx = \mathbf{x \ln x - x + C}$$

Ejercicio 11 Partes: x·cos(x)

Calcula: $\int x \cos x \, dx$.

Ver Solución Paso a Paso

$u = x \implies du = dx$; $dv = \cos x dx \implies v = \sin x$.

$$\int x \cos x dx = x \sin x - \int \sin x dx = x \sin x - (-\cos x) + C = \mathbf{x \sin x + \cos x + C}$$

Ejercicio 12 Racional con raíces reales simples

Calcula descomponiendo en fracciones simples: $\int \frac{5x - 2}{x^2 - 4} \, dx$.

Ver Solución Paso a Paso

$\frac{5x - 2}{(x - 2)(x + 2)} = \frac{A}{x - 2} + \frac{B}{x + 2} \implies 5x - 2 = A(x + 2) + B(x - 2)$.

• Para $x = 2$: $8 = 4A \implies A = 2$.

• Para $x = -2$: $-12 = -4B \implies B = 3$.

$$= \int \frac{2}{x - 2} dx + \int \frac{3}{x + 2} dx = \mathbf{2\ln|x - 2| + 3\ln|x + 2| + C}$$

Ejercicio 13 Área bajo una parábola

Calcula el área del recinto limitado por la parábola $y = 4 - x^2$ y el eje de abscisas $y = 0$.

Ver Solución Paso a Paso

1º Puntos de corte con el eje OX: $4 - x^2 = 0 \implies x = \pm 2$.

2º La parábola queda por encima del eje en $[-2, 2]$. Por simetría par:

$$\text{Área} = \int_{-2}^2 (4 - x^2) dx = 2 \int_0^2 (4 - x^2) dx = 2 \left[4x - \frac{x^3}{3}\right]_0^2 = 2 \left(8 - \frac{8}{3}\right) = 2 \left(\frac{16}{3}\right) = \mathbf{\frac{32}{3}\text{ u}^2} \approx 10.67\text{ u}^2$$

Ejercicio 14 Área entre recta y parábola

Halla el área comprendida entre $f(x) = x^2$ y la recta $g(x) = 2x$.

Ver Solución Paso a Paso

Puntos de corte: $x^2 = 2x \implies x(x - 2) = 0 \implies x_1 = 0, x_2 = 2$.

En $[0, 2]$, la recta $2x$ está por encima de $x^2$:

$$\text{Área} = \int_0^2 (2x - x^2) \, dx = \left[x^2 - \frac{x^3}{3}\right]_0^2 = \left(4 - \frac{8}{3}\right) - 0 = \mathbf{\frac{4}{3}\text{ u}^2}$$

Ejercicio 15 Cambio de variable simple

Calcula mediante cambio de variable: $\int \frac{e^x}{1 + e^x} \, dx$.

Ver Solución Paso a Paso

Sea $t = 1 + e^x \implies dt = e^x dx$:

$$= \int \frac{1}{t} \, dt = \ln|t| + C = \mathbf{\ln(1 + e^x) + C}$$

Ejercicio 16 Integral racional con división

Calcula: $\int \frac{x^2 + 1}{x - 1} \, dx$.

Ver Solución Paso a Paso

Como grado del numerador $\ge$ denominador, dividimos: $(x^2 + 1) : (x - 1) = x + 1$ con resto 2.

$$\frac{x^2 + 1}{x - 1} = x + 1 + \frac{2}{x - 1}$$

$$= \int (x + 1) dx + \int \frac{2}{x - 1} dx = \mathbf{\frac{x^2}{2} + x + 2\ln|x - 1| + C}$$

Nivel 3

Problemas Oficiales de Examen EvAU Cantabria (17 a 22)

Ejercicio 17 Partes doble: x^2·e^x

Calcula la primitiva de $f(x) = x^2 e^{2x}$.

Ver Solución Paso a Paso

1ª iteración: $u = x^2 \implies du = 2x dx$; $dv = e^{2x} dx \implies v = \frac{1}{2}e^{2x}$.

$$= \frac{1}{2}x^2 e^{2x} - \int x e^{2x} dx$$

2ª iteración sobre $\int x e^{2x} dx$: $u = x \implies du = dx$; $dv = e^{2x} dx \implies v = \frac{1}{2}e^{2x}$.

$$\int x e^{2x} dx = \frac{1}{2}x e^{2x} - \int \frac{1}{2}e^{2x} dx = \frac{1}{2}x e^{2x} - \frac{1}{4}e^{2x}$$

Sustituyendo: $$= \frac{1}{2}x^2 e^{2x} - \frac{1}{2}x e^{2x} + \frac{1}{4}e^{2x} + C = \mathbf{e^{2x}\left(\frac{x^2}{2} - \frac{x}{2} + \frac{1}{4}\right) + C}$$

Ejercicio 18 Área con múltiples recintos

Calcula el área encerrada entre la curva $f(x) = x^3 - 3x$ y la recta $g(x) = x$.

Ver Solución Paso a Paso

Puntos de corte: $x^3 - 3x = x \implies x^3 - 4x = 0 \implies x(x - 2)(x + 2) = 0 \implies x \in \{-2, 0, 2\}$.

Hay dos recintos simétricos:

• En $[-2, 0]$, la cúbica va por arriba: $\int_{-2}^0 (x^3 - 4x) dx = \left[\frac{x^4}{4} - 2x^2\right]_{-2}^0 = 0 - (4 - 8) = 4\text{ u}^2$.

• En $[0, 2]$, la recta va por arriba: $\int_0^2 (4x - x^3) dx = 4\text{ u}^2$.

$$\text{Área total} = 4 + 4 = \mathbf{8\text{ u}^2}$$

Ejercicio 19 Área con recta tangente

Dada $f(x) = x^2 - 4x + 3$, calcula el área comprendida entre la curva, su recta tangente en el punto de abscisa $x = 3$ y el eje OY ($x = 0$).

Ver Solución Paso a Paso

1º Recta tangente en $x = 3$: $f(3) = 0$. $f'(x) = 2x - 4 \implies m = f'(3) = 2$. Recta: $y - 0 = 2(x - 3) \implies y = 2x - 6$.

2º En $[0, 3]$, la parábola está siempre por encima de su tangente:

$$f(x) - y_{\text{tang}} = (x^2 - 4x + 3) - (2x - 6) = x^2 - 6x + 9 = (x - 3)^2$$

$$\text{Área} = \int_0^3 (x - 3)^2 dx = \left[\frac{(x - 3)^3}{3}\right]_0^3 = 0 - \left(\frac{-27}{3}\right) = \mathbf{9\text{ u}^2}$$

Ejercicio 20 Racional con raíz doble

Calcula: $\int \frac{x}{(x - 1)^2} \, dx$.

Ver Solución Paso a Paso

Descomposición: $\frac{x}{(x - 1)^2} = \frac{A}{x - 1} + \frac{B}{(x - 1)^2} \implies x = A(x - 1) + B$.

Para $x = 1 \implies B = 1$. Igualando coeficientes: $A = 1$.

$$= \int \frac{1}{x - 1} dx + \int (x - 1)^{-2} dx = \mathbf{\ln|x - 1| - \frac{1}{x - 1} + C}$$

Ejercicio 21 Parámetro para área fija

Halla el valor del parámetro $a > 0$ tal que el área encerrada entre la parábola $y = a x^2$ y la recta $y = a^2 x$ sea igual a $9/2\text{ u}^2$.

Ver Solución Paso a Paso

Cortes: $a x^2 = a^2 x \implies a x (x - a) = 0 \implies x_1 = 0, x_2 = a$.

$$\text{Área} = \int_0^a (a^2 x - a x^2) \, dx = \left[a^2 \frac{x^2}{2} - a \frac{x^3}{3}\right]_0^a = \frac{a^4}{2} - \frac{a^4}{3} = \frac{a^4}{6}$$

Igualamos al área dada: $\frac{a^4}{6} = \frac{9}{2} \implies a^4 = 27 \implies \mathbf{a = \sqrt[4]{27} = 3^{3/4} \approx 2.28}$

Ejercicio 22 Partes cíclica de examen

Calcula la integral cíclica clásica: $I = \int e^x \cos x \, dx$.

Ver Solución Paso a Paso

1ª vez: $u = e^x \implies du = e^x dx$; $dv = \cos x dx \implies v = \sin x$.

$$I = e^x \sin x - \int e^x \sin x \, dx$$

2ª vez sobre la nueva integral: $u = e^x \implies du = e^x dx$; $dv = \sin x dx \implies v = -\cos x$.

$$\int e^x \sin x dx = -e^x \cos x - \int -e^x \cos x dx = -e^x \cos x + I$$

Sustituyendo en la ecuación original: $I = e^x \sin x - (-e^x \cos x + I) = e^x(\sin x + \cos x) - I$.

Pasamos $-I$ sumando a la izquierda: $2I = e^x(\sin x + \cos x) \implies \mathbf{I = \frac{e^x(\sin x + \cos x)}{2} + C}$
